# Alexander Poluboyarinov

Co-founder & CEO of **[sayso](https://saysoio.com)**: a pre-signing check for AI agents' onchain transactions.

Before an AI agent signs, sayso simulates the exact transaction, checks it against the owner's rules written in plain language, and answers **allow**, **ask the owner**, or **block**. It never holds keys or funds.

- Open-source SDK: [saysoio/sdk](https://github.com/saysoio/sdk) (on npm as `saysoio`)
- Website: [saysoio.com](https://saysoio.com)
